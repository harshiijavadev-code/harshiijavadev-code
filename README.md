### SupportIQ
**Spring Boot SaaS Support Ticket Management Platform**

</div>

**Overview**
SupportIQ is a backend platform for managing customer support tickets, built to explore real-world backend concerns — authentication, authorization, layered architecture, and API design — in a single cohesive system.

**Features**
- 🔐 JWT-based authentication with stateless session management
- 🛂 Role-based authorization (Admin / Agent) enforced via Spring Security
- 🎫 RESTful APIs for ticket creation, assignment, and lifecycle management
- 🤖 AI-powered ticket categorization for faster triage
- 💬 AI-based sentiment analysis on incoming tickets
- 📊 Manager analytics dashboard for ticket and team metrics
- ⚠️ Centralized exception handling and request validation
- 📦 DTO-based request/response layer to decouple entities from API contracts

**Architecture**
- Layered architecture: Controller → Service → Repository
- DTO pattern for clean API boundaries
- Global exception handling via `@ControllerAdvice`
- Relational schema modeled in PostgreSQL
